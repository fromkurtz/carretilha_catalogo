Catálogo

Fica guardado só neste navegador, protegido pela senha abaixo.
Como criar o token
  1. No GitHub, abra Settings > Developer settings > Personal access tokens > Fine-grained tokens.
  2. Clique em Generate new token e escolha Only select repositories, marcando só o repositório do catálogo.
  3. Em Repository permissions, deixe Contents como Read and write.
  4. Gere o token e cole aqui.
